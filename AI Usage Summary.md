# AI Usage Note

Project: AI Test Case Generator

## What AI Helped With

Artificial Intelligence was used in two ways:

1. Ollama (Llama 3) was used to generate Positive, Negative, and Edge test cases from user stories.
2. Generative AI assistants were used during development for architecture suggestions, UI improvements, debugging support, authentication implementation guidance, and documentation generation.

## What AI Got Wrong

* Some generated test cases were duplicated.
* Certain edge cases were occasionally missed.
* Generated outputs sometimes required prompt refinement.
* Initial dashboard API implementation contained routing issues that required manual debugging.

## Best Prompts Used

* Generate comprehensive Positive, Negative, and Edge test cases in Gherkin format.
* Analyze a user story and identify actors, inputs, outputs, validations, and expected scenarios.
* Create React dashboard analytics for generated test case metrics.
* Implement JWT authentication using Node.js, Express.js, and SQLite.

## Human Contributions

* Project architecture design.
* Database schema creation.
* Frontend integration.
* Authentication implementation.
* Dashboard analytics.
* Testing and debugging.
* Documentation and deployment.
