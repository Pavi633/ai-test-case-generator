## Prompt 1 – Requirement Analysis

Analyze the given user story and identify actors, goals, inputs, outputs, validations, and functional requirements relevant for software testing.

## Prompt 2 – Test Case Generation

Generate Positive, Negative, and Edge test cases from the provided user story.

## Prompt 3 – Gherkin Conversion

Convert generated test cases into Given-When-Then format compatible with Cucumber and Behave.

## Prompt 4 – Coverage Evaluation

Evaluate generated scenarios and estimate test coverage.

## Prompt 5 – Security and Validation Testing

Generate validation and security-related test scenarios for the given user story.
